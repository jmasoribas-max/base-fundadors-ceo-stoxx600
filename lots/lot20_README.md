# Lot 20 · Fonts noves per als dubtes oberts (24/11/2026)

El triatge del 24/11 va identificar 41 grups de dubtes que només es podien tancar amb una cerca nova. Set agents van fer la cerca (4 empreses cadascun) seguint les instruccions del triatge, i un verificador independent per grup va comprovar cada cita al document baixat i cada proposta.

## Què fa

- **129 entrades noves** al registre (`L20-…`), totes amb veredicte «ok» del verificador. 120 són [V] (Claude torna a baixar el document i hi troba la cita literal, o la cita és al fitxer baixat per la cerca) i 9 [NV] `pendent_arxiu` (ICAP/NEX: el web bloqueja la descàrrega; ho recuperarà el flux de Wayback).
- Les 34 cites que el verificador va marcar «corregir» i la que va marcar «rebutjar» **no** s'importen.
- **37 tancaments** (32 files) a `estat/dubtes_tancats.csv`: només les files on **tots** els dubtes oberts queden resolts per una cerca amb resultat «resolt» i veredicte «ok».
- **Cap canvi d'etiqueta (FounderCEO) ni de CEO (`ceos`).** Els canvis de traçabilitat que proposa la cerca (p. ex. `regles` b → d a Allreal, Siemens Gamesa i RTL) van a la frase del tancament i s'aplicaran al lot de correcció.
